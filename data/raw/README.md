# Raw data

Place authorized raw inputs here or configure `raw_data` in
`configs/paths.local.json`. See [the data documentation](../../docs/DATA.md).
Dataset records and product images are not included in this release and are ignored by Git.

## Data access

No datasets or product images are included. Download public Amazon data using the
links in [Data access and preparation](../../docs/DATA.md#dataset-availability).
For private Suning data, please contact the authors to request access.
